🧪 Test Case Documentation

Corporate Learning Progress, Intervention & Compliance Tracking System — Problem Statement 3

Propeller Technothon SaaS Application Multi-Tenant Platform

📝 1. Test Plan

This test plan covers a multi-tenant SaaS application. In addition to standard functional testing, it includes SaaS-specific test dimensions: tenant isolation, subscription tier enforcement, per-tenant rate limiting, SSO integration, and cross-tenant security.

1.1 Objectives

  • Validate all functional requirements per use case
  • Verify tenant data isolation — no cross-tenant data leakage under any scenario
  • Confirm subscription tier limits are correctly enforced per tenant
  • Ensure risk rule engine fires correctly for all configured conditions per tenant
  • Validate intervention workflow, effectiveness calculation, and compliance reporting
  • Verify RBAC at both platform-level (Super Admin) and tenant-level roles
  • Assess system performance under multi-tenant concurrent load
  • Validate per-tenant rate limiting on all API endpoints
  • Verify SSO (SAML/OIDC) integration per tenant

1.2 Test Scope

✅ In Test Scope

  • Tenant onboarding & provisioning
  • Tenant data isolation (RLS)
  • Subscription tier enforcement
  • Per-tenant API key & rate limiting
  • SSO configuration (SAML/OIDC)
  • Super Admin portal functions
  • Data ingestion per tenant
  • Employee profile aggregation
  • Risk rule engine (all types)
  • At-risk classification & alerts
  • Intervention workflow & effectiveness
  • Compliance report generation
  • Role-based dashboards (all roles)
  • Multi-tenant performance & load
  • Authentication & RBAC security

🚫 Out of Test Scope

  • Source system internal logic
  • Third-party email/SMS infrastructure
  • External billing system (Stripe/Chargebee)
  • Native mobile apps (Phase 1)
  • ML/AI predictive models (Phase 2)
  • White-labelling (Phase 2)
  • Multi-region data residency (Phase 3)
  • Penetration testing (separate engagement)
  • Browser compatibility beyond Chrome/Edge/Firefox

1.5 Entry & Exit Criteria

🟢 Entry Criteria

  • Feature development complete
  • Unit tests pass (>80% coverage)
  • Multi-tenant QA environment provisioned with 5 test tenants
  • Test data prepared per tenant
  • Test cases reviewed and approved
  • Tenant isolation test suite ready

🔴 Exit Criteria

  • All Critical/High test cases pass
  • Zero cross-tenant data leakage in isolation tests
  • Tier enforcement validated for all 3 tiers
  • Performance SLAs met under multi-tenant load
  • No open Critical or High severity bugs
  • UAT sign-off from pilot tenants
  • Test summary report published
